Everything in one window

Tabs, a session tree and a ribbon of tools, with the workflow of a classic remote toolbox and a native macOS look.

Many protocols

Local terminal, SSH, SFTP, FTP/FTPS, Telnet, Rlogin, raw TCP, serial, Mosh, VNC, RDP launcher and a web browser tab.

SFTP side panel

Browse and transfer files next to your SSH terminal with drag and drop, permissions and an integrated text editor.

MultiExec

See all open terminals at once and type in all of them, with an Exclude checkbox on each.

SSH tunnels

Local, remote and dynamic (SOCKS) forwarding, saved per session or managed globally.

Mini Linux

An Alpine Linux virtual machine inside the app with a shared Mac folder and persistent packages and settings.

Macros & snippets

Record and replay keystrokes, or save snippets with variables and pauses.

Network tools

Port and network scanner, ping, traceroute, DNS, whois, Wake-on-LAN, SSH key manager, hashes, subnet calculator, HTTP file server.

Security first

Passwords in the macOS Keychain, input validation, hardened runtime, optional master password, host key checking. See the security notes.

No limits

No cap on sessions, tabs or tunnels. Imports .mxtsessions files from MobaXterm.

FAQ

Is it free?

Yes. ShellDock is open source and has no session limits or paid tiers.

Is it MobaXterm for Mac?

No. It is an independent, original app inspired by that kind of workflow, with no code or assets from other products. Not affiliated with Mobatek.

What isn't there yet?

No built-in X server (use XQuartz), no embedded RDP, no XDMCP, and keyword highlighting only on Telnet/TCP/serial. The parity document lists the real status.

Does Mini Linux need internet?

Only the first time: it downloads Alpine Linux (~90 MB, checksum verified) and keeps it cached.
